# Claude Codeへの実装依頼「生地から品番を探す」

`die-link-vercel` に、品番が分からない生地をカメラで撮り、その生地を使う品番候補を表示する機能を追加してください。実際に作業者から出た要望です。同じ生地を使っていても、抜型が異なると別の品番になることがあります。撮影だけで候補を数点まで絞れれば、現場では十分役に立ちます。

## 作業者の操作

1. スマホの「知る」画面で **「生地から品番を探す」** を押します。品番入力やQR読み取りの前に使える入口にしてください。
2. 手元の生地を撮影します。AIが、登録済みの生地写真から色・柄・表面の質感が似ている見本を探します。
3. 見本写真と **「この生地を使う品番候補 4件」** のような件数を出し、その生地に登録された品番をすべて表示します。各行には `Book / WorkCord` と品名を出し、押すと既存の品番検索を開きます。進行中の受注がある品番が分かる場合は上から並べます。
4. 似ている生地が複数ある場合は、見本写真と材質名を見比べて選べるようにします。写真の状態などで判断がつかない場合は、再撮影や「候補が見つかりませんでした」の案内を出します。

たとえば、撮影した生地を使う `Ta / 1001`、`Ta / 1002`、`Ko / 1001` が登録されていれば、3品番をすべて出してください。品番一覧の単位は `Book` と `WorkCord` の組です。同じ品番の受注が複数行あれば、候補の品番は1件として扱います。

## データと画像

- 検索に必要な対応は **生地の識別子 → 生地の見本写真 → その生地を使う全品番** です。既存の材料マスタや写真台帳で対応を確認できる場合は再利用してください。対応が未整備なら、まず現場でよく使う数種類について、現物を知る担当者が確認した見本写真と品番の組で試せるようにしてください。
- Airtableの `skydbss / TableJuchu` には `Material`（材質）、`Paper_Size`（原紙）、`Book`、`WorkCord`、`ItemName` があります。`材料` は工程管理用の状態を返す数式です。材質の候補調査には `Material` を利用できます。生地との対応を確定する際は、材質欄の表記と見本写真を確認してください。
- 2026年11月18日に納期の新しい順で100受注を確認しました。`Material` が `B/C5*C5` の受注は20の異なる品番にまたがっていました。材質の空欄が21件あり、`E/C5*C5 588*599.5` のように寸法を含む表記もありました。材質の文字列だけで同じ生地だと確定すると、まとめ間違いや取りこぼしが起こり得ます。[受注テーブル](https://airtable.com/appwAnJP9OOZ3MVF5/tbl3r511iE8MS22vm)
- 見本には、実際の生地を撮ったと確認できる画像を使ってください。「知る」の既存のDrive資料には `-zu` の図面や `-si` のシール画像があります。品番ごとの写真がなくても、生地との対応が確認できている品番は一覧に含めます。

## 実装で参照する箇所

- [`public/scan-spec-google.html`](../public/scan-spec-google.html) と [`public/js/scan-spec-google.js`](../public/js/scan-spec-google.js) に「知る」画面と既存のカメラ操作があります。撮影と画像縮小には `captureAiFrame` を再利用できるか確認してください。
- [`api/material-match.js`](../api/material-match.js) は、既知の `Book`・`WorkCord` に対して撮影画像と参照画像を1対1で比べる生地照合です。新しい検索は、品番を指定せずに生地の見本を探す入口です。Vercelの関数数を抑えている現構成に合わせ、検索用の処理をどのAPI入口に載せるか判断してください。
- [`api/_vision.js`](../api/_vision.js) の `callVisionJSON` とサーバー側の `OPENAI_API_KEY` を再利用できます。既定モデルは `gpt-6.2-sol` です。初期版は、登録済みの見本を少数ずつ比較する構成で検証できます。見本が多い場合は検索の前段で候補を絞る方法を検討してください。
- AIからは、送った見本の中で一致候補となる生地の識別子を受け取ります。識別子をサーバーで検証し、実際に表示する品番は登録データから引きます。複数ページにまたがる場合も、選んだ生地に紐づく品番をすべてたどれるようにしてください。
- 検索はログイン済みの利用者向けの読み取り操作です。生地照合済みの記録は既存の照合操作で行います。結果の表示や再撮影は品番を選ぶ前に行えるようにしてください。

## 完了時に確かめたいこと

- 品番・QRなしで、撮影から「この生地を使う品番候補」の一覧まで進める。
- 一つの生地に別の抜型の品番を複数登録した場合、紐づく品番が全件出る。受注行が複数あっても同じ品番は1回表示される。
- 複数の生地が似ている場合に見本を選び直せる。見本なし・判定不能・通信失敗でも、理由が分かり、再撮影や再確認ができる。
- 検索結果から開いた品番が正しく、従来の品番指定による生地照合も動く。

試した生地と品番の組、候補の取りこぼし、撮影から候補表示までにかかった時間を実装結果に添えてください。
